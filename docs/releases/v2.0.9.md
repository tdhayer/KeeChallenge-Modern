# KeeChallenge-Modern v2.0.9

## Highlights

- Signed update-feed verification with a pinned RSA public key. Update checks remain disabled if verification cannot be configured; YubiKey key-provider registration is independent of update-check setup.
- Strict 20-byte challenge-response secret validation, including hexadecimal and whitespace handling.
- Sanitized user-facing errors with diagnostic details available to maintainers.
- Improved clearing of temporary secret, response, and encryption buffers.
- Improved Abort, timeout, and immediate-retry handling during YubiKey operations.
- Regression tests for KeePass plugin loading, challenge modes, decryption, input validation, buffer clearing, and signed/tampered/unsigned update feeds.
- Updated pinned GitHub Actions: checkout 7.0.1, setup-dotnet 6.0.0, and action-gh-release 3.0.3.

## Requirements and installation

Windows, KeePass 2.x, .NET Framework 4.8, and a YubiKey configured for HMAC-SHA1 challenge-response are required.

1. Back up your database and its matching KeeChallenge XML sidecar.
2. Close KeePass.
3. Verify the download against the supplied SHA-256 checksum.
4. Extract `KeeChallenge.dll` and both `32bit` and `64bit` folders into KeePass's `Plugins` folder, replacing the previous plugin files. Do not retain duplicate plugin DLLs.
5. Start KeePass and confirm KeeChallenge appears under Tools > Plugins before opening your database.

No database format migration or YubiKey reprogramming is required. Preserve the database's XML sidecar when moving or backing up the database.
